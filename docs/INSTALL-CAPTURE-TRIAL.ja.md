# KM003C 統合キャプチャ導入ツール Windows試験版

対象は既知の純正FW 2.0.7を使う **HW 2.1（ROM 4MB）とHW 2.3** です。入るキャプチャ版はHW 2.1が起動番号付きv4、HW 2.3が0.3.1です。統合版v1のメニュー2による同一版の書き込み省略と通常復帰を、それぞれ1台で確認しました。統合版の初回導入・復元を通した実機検証は未実施です。書き込みに失敗すると本体が起動できなくなる場合があります。

## はじめに

1. Windows 10／11の64bit版を使用します。配布された `.zip.sha256` の値と、PowerShellの `Get-FileHash -Algorithm SHA256 "ZIPのフルパス"` の結果を照合してください。
2. ZIPの全ファイルを新しいフォルダに展開し、`Install.cmd` を起動します。PowerShell 5.1を使用します。
3. MToolsや旧導入ツールを閉じます。本体は1台だけとし、測定用ポート2つを空け、側面HIDだけを接続します。既存バックアップを使う場合は、採取したときと同じPC・同じ物理USBポートを使います。
4. 更新・復元前に必要なBMPをPCへコピーします。側面HIDを抜き、画面が消えたら左右だけを押しながら再接続します。`USB SCREENSHOTS` が出たら離し、USBドライブからBMPをコピーします。終わったら抜いて、ボタンを押さず通常起動します。キャプチャ版の更新では画像を消去する必要はありません。

## メニュー

- **1 初回導入**。未改変の純正FWを通常起動して始めます。読み取ったシリアルを本体と照合し、表示どおり入力します。HW 2.1は本体情報でROM 4MBを確認し、`ROM4MB` と入力します。純正バックアップを作成し、Exitを押しながら側面HIDをつなぎ直してBOOT Loaderに入り、案内に従って読み取り照合を行います。出力された `stock` と作業フォルダ全体を安全な別の場所にもコピーしてから書き込みを承認してください。
- **2 既存バックアップから導入・更新**。通常起動で始めます。元の純正バックアップの `manifest.json` があるフォルダ、またはその中に `stock` がある親フォルダを指定します。HW 2.1は旧QR残存の復旧と最初のキャプチャ版導入に使った元のバックアップ、HW 2.3は旧版ツールの `stock-…` フォルダを使用できます。DFU照合を完了したバックアップが必要です。HW 2.1の起動番号なし版／起動番号付きv2・v3は読み取った内部状態から識別します。HW 2.3で以前の拡張から更新するときは、その旧版の `bundle` フォルダを指定する場合があります。同じ版が入っていれば、書き込みを省略して起動確認へ進みます。
- **3 純正へ復元**。同じ個体の元の純正バックアップを指定します。キャプチャ版が起動できる場合は、BMPを退避してから現在の版の本体操作で画像を消去し、通常起動に戻して開始します。画像を消去してから `CLEARED` と入力します。通常起動できずBOOT Loaderから復元する場合は、バックアップと同じ個体・ポートであることを確認して `DFU` と入力し、画像消去を確認できない場合は `EMERGENCY` を選べます。内部FWの復元手順です。
- **4 本体確認**。読み取り専用でHWとモードを確認します。
- **5 HW 2.1の既知の旧QR残存を復旧**。旧QR残存が含まれる元のバックアップを使います。内部全体が記録された既知の状態に一致したときだけ、`CLEAN-QR` を入力すると復旧します。純正画面と機能を確認してからメニュー2で導入します。
- **6 既存バックアップの検証と準備**。個体バックアップを検証して、導入・復旧データを新規フォルダに準備します。USB接続なしで試せます。

本体とバックアップ、USBポート、ローダー、保護領域のいずれかが一致しなければ停止します。更新元を識別できなかった場合も処理を中断します。失敗時は表示された作業フォルダを保管してください。転送中に失敗した場合は側面HIDを抜いて、次の実機操作時にExitを押しながら接続し直してください。元のバックアップや生成した個体データは共有せずに保管してください。

通常起動後は、左右を短く同時押しして離すと通常キャプチャ、2秒以上は対応画面の縦長キャプチャです。`CAPTURE SAVED` を確認し、再接続でUSBドライブからBMPを取得します。

## 同梱ツール

HW 2.1は協力試験用v4のバックアップ／更新ツールとキャプチャデータ、HW 2.3は公開版0.3.1のバックアップ／更新ツールとキャプチャデータを使用します。同梱元のSHA-256は `capture-trial-manifest.json` に記録しています。HW 2.3側のソースは [v0.3.1-fw2.0.7](https://github.com/inuchanbt/km003c-fw-extensions/tree/v0.3.1-fw2.0.7) で確認できます。
