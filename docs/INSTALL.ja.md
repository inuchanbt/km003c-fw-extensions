# 導入と復旧

[English](INSTALL.md)

初回公開はソースのみです。ビルド出力は拡張部品で、そのまま書き込む純正イメージではありません。対象は[既知のHW2.3／FW2.0.7](COMPATIBILITY.ja.md)で、所有者自身の検証済みバックアップと既知loaderが必要です。他人の個体向けパッケージや出所不明のROMを流用しません。

1. 純正アプリ・loader・校正・内部末尾を、チェックサムと復旧確認結果とともに手元で保持します。固定版のバックアップツールはtools/prepare_native_host.pyで準備します。[専用ホスト](../native-host/README.ja.md)を参照してください。
2. tools/build_firmware.pyでQRまたはキャプチャを1種類作成します。本体では排他的です。
3. `python tools/prepare_overlay207.py --stock <qualified-backup> --build <variant-build> --output artifacts/private-candidate` で手元専用の候補を作ります。
4. 専用ホストでパッケージ化・照合し、DFU・書込・起動・読み戻しの照合付き手順に従います。ハッシュ・loader・校正・保護末尾の検査を回避しません。
5. 起動後の内部全領域と校正を再確認します。対応する2段階の復旧セットも先に手元へ残します。

通常起動はボタンを押さず側面USBへ再接続します。Exitを押しながら再接続すると純正ブートローダーです。Exit＋OKも純正loader操作で、撮影には使いません。

キャプチャ先は空白またはキャプチャ所有のNORである必要があります。起動だけでは消去しません。既知の旧DOOMパックは本体で2段階の明示確認をした場合だけ転用し、不明なデータは拒否します。[操作と領域配置](SCREEN-CAPTURE-207.ja.md)を確認してください。

旧内部画像0x78000〜0x7C000は、末尾をバックアップと照合する更新の前に退避・明示消去が必要です。互換性を確認した外部画像対応版間では画像を保持して更新できます。追加バンクを知らない旧版へ戻す前は、現在のキャプチャ版で両バンクをPCへ退避・明示消去してください。内部FWの復旧は外部画像を自動消去せず、転用したゲームデータも復元しません。

個体用の検証済みバックアップはこの公開リポジトリには含まれません。純正FWが更新された場合は別の移植・検証が必要です。
