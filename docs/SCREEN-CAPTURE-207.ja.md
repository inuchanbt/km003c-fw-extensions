# 画面キャプチャ — 純正FW 2.0.7 / HW 2.3

[English](SCREEN-CAPTURE-207.md)

screen版はQR表示を画面キャプチャへ置き換えます。現在の実装は18cで、プロジェクトのリリース版とは別に記録します。

## 操作

1. 撮りたい画面で左右を0.5〜2秒未満押して離すと通常240×240撮影、2秒以上押すと縦長撮影です。CAPTURE SAVEDを待ってから電源を外します。押し続けても1回だけ保存します。
2. 測定側の端子を空け、左右だけを押しながら側面HID USBをPCへ再接続します。USB SCREENSHOTSが出たら離し、読み取り専用KM003CドライブからBMPをコピーします。
3. ボタンを押さずに再接続すると通常の測定画面へ戻ります。

Exit＋OKは純正のブートローダー操作で、撮影には使いません。左右単独入力は同時押し判定のため最大150 ms遅れます。同時押しはGUIと純正の別ボタン判定の両方で抑止し、監視タイマー更新は維持します。

縦長撮影は幅240の純正ウィンドウ本文、最大240×2048に対応します。見出しは一度だけ入り、元のスクロール位置とバー表示へ戻ります。あふれない画面は通常サイズ、対応外はLONG CAPTURE UNAVAILABLEです。2回の再描画内容が一致しなければDISPLAY CHANGED / RETRYとして記録を公開しません。

## 名前と容量

新しい画像名は英大文字のメニュー名＋全メニュー共通の最小2桁連番です。例はUSBCEMARKER41.BMP、CAPACITY48.BMPです。空白・記号は省き、不明な画面名はSCREEN、旧画像はSC000001.BMP形式を維持します。必要な桁を切り捨てません。日時は固定FAT値で、撮影日時ではありません。

実保存は**1472 KiB、管理上限96枚**です。1枚16 KiBの予約だけなら空の領域で92枚が目安で、小さい画像は区画を共有します。大きな縦長画像や中断した予約で先に容量が埋まる場合があります。満杯でも古い画像を自動上書きしません。

USBに見える**128 MiBは仮想FAT16容量**で、圧縮RGB565を上向きのBMPへ展開して見せるためのものです。実保存容量ではありません。PCからの書込・フォーマット・削除は拒否します。

| 外部NOR範囲 | 用途 |
| --- | --- |
| 0x000000〜0x100000未満 | 従来1 MiBの画像。試験機では既知の旧ゲーム領域を明示転用 |
| 0x100000〜0x300000未満 | 純正測定記録を保護 |
| 0x300000〜0x380000未満 | 純正更新データを保護 |
| 0x380000〜0x3F0000未満 | 追加448 KiBの画像 |
| 0x3F0000〜0x400000未満 | 純正設定を含む最後64 KiBを保護 |

起動時に追加先の空白・所有情報とCRCを確認します。不明な内容があれば追加先を無効にし、従来領域だけを使います。保存は追加先を優先し、空きがなければ従来領域を使います。撮影時の自動消去はありません。所有マーカー、長さ・連番の反転値、CRC、読み戻し、最終コミットで記録を公開します。純正のバス排他とページ境界を守る単ページ書込を使います。別FWへ同じ領域を無条件に流用しません。

ARMの96枚管理表は従来64枚と同じ776バイトです。番号を不揮発ヘッダーから参照してRAMで重複保持しません。全画面バッファや圧縮画像全体を確保せず、2回の一致する描画と256バイトの小分け保存を使います。

## 消去・更新

必要な画像を先にPCへコピーします。USB SCREENSHOTSでOKだけを2秒押し、ERASE ALL CAPTURES?が出たら全部離し、もう一度OKだけを2秒押します。Exitは取消です。有効な両バンクの所有を消去前に確認し、不明なデータはフォーマットしません。完了後は通常接続へ戻します。

特定の既知DOOMパックの場合だけERASE DOOM DATA?となり、別の2秒OK確認後に転用します。これは認識されたゲームデータを消す明示操作で、起動だけでは消しません。不明なデータは拒否します。

互換性を確認したキャプチャ版同士なら外部画像を保持して更新できます。追加バンクを知らない旧版へ戻す前は、現在版で両バンクを退避・明示消去してください。旧内部画像は更新ツールの保護末尾照合が必要です。[導入と復旧](INSTALL.ja.md)を参照してください。
